# YawaChat — сайт

Лендинг YawaChat: **https://yawaside.github.io/YawaChat-web/**

## Почему раньше была белая страница

GitHub Pages отдавал из корня репозитория **исходный** `index.html`, в котором подключён
`/src/main.tsx`. Браузер не умеет выполнять `.tsx` (это TypeScript + JSX, его нужно
собирать), файл не загружался — React не монтировался, и страница оставалась пустой.

Теперь в корне лежит **уже собранный** сайт: один самодостаточный `index.html`
(HTML + CSS + JS + логотип внутри), поэтому он работает без сборки на стороне GitHub
и не зависит от пути (корень домена, подпапка `/YawaChat-web/` или свой домен).

## Структура

```
index.html      ← ГОТОВЫЙ сайт (генерируется автоматически, не редактировать руками)
.nojekyll       ← отключает обработку Jekyll на GitHub Pages
web/            ← исходники (React 19.3 + Vite + Tailwind 4)
  index.html
  src/
  package.json
```

## Дизайн

Сайт переписан с нуля по гайдлайнам из скиллов
[anthropics/skills](https://github.com/anthropics/skills) (`frontend-design`) и
[vercel-labs/agent-skills](https://github.com/vercel-labs/agent-skills)
(`web-design-guidelines`, `react-best-practices`, `composition-patterns`, `react-view-transitions`).

Что из этого следует в коде:

- **Бумажный фон и тёмные окна.** Основа — светлая «бумага» `#f7f6fa`, единственные
  объёмные объекты — тёмные окна приложения (`--color-night`). Цвет на странице
  работает как данные: каждая площадка имеет свой цвет, больше нигде цвет не «декоративный».
- **Типографика:** Bitter (слэб-сериф, заголовки) + Onest (текст и интерфейс).
  Оба шрифта лежат в `web/src/fonts` (кириллица + латиница, подмножества woff2),
  лицензия SIL OFL — файлы лицензий рядом.
- **Токены** — в `web/src/index.css` (`@theme`): цвета, шрифты, радиусы. Компоненты
  собираются из токенов, а не из «стеклянных» карточек и градиентов.
- **Доступность:** пропуск к содержимому, видимый фокус только с клавиатуры
  (`:focus-visible`), `aria-expanded`/`aria-controls` у аккордеонов, `role="status"`
  у статуса загрузки, семантические `time`, `ol`, `dl`, `figure/figcaption`.
  Контраст всех текстовых пар проверен: минимум 4.5:1.
- **Движение:** анимируется только живая лента (это суть продукта), при
  `prefers-reduced-motion` анимации выключаются. Раскрытие описания релиза —
  CSS-аккордеон без измерений высоты, появление новых версий — через
  `<ViewTransition>` из React 19.3 (там, где браузер это умеет).
- **Производительность:** весь сайт — один `index.html` (~490 КБ, ~240 КБ gzip),
  шрифты и логотип внутри, внешних запросов нет (кроме GitHub API для релизов).

## Разработка

```bash
cd web
npm install
npm run dev      # локальная разработка: http://localhost:5173
npm run build    # сборка + копирование результата в ../index.html
```

`npm run build` собирает всё в `web/dist/index.html` и копирует его в корень репозитория.
После любых правок исходников нужно выполнить сборку и закоммитить обновлённый `index.html`
(это проверяет workflow `.github/workflows/build.yml`).

> ⚠️ Не загружайте исходный `index.html` в корень репозитория — исходники живут в `web/`.
> Если залить туда исходник, сайт снова станет белым.

## Как изменить адрес сайта

Сейчас адрес `https://yawaside.github.io/YawaChat-web/` складывается из имени аккаунта
(`yawaside`), имени репозитория (`YawaChat-web`) и включённого GitHub Pages.
Варианты:

1. **Свой домен (лучший вариант, например `yawachat.ru`)** — адрес станет
   `https://yawachat.ru`. Нужно: купить домен, в GitHub → Settings → Pages → Custom domain
   вписать домен, в DNS у регистратора добавить `CNAME` на `yawaside.github.io`
   (для домена без `www` — четыре `A`-записи GitHub Pages), включить «Enforce HTTPS».
   В репозиторий можно добавить файл `CNAME` с доменом — сайт продолжит работать.
2. **Переименовать репозиторий** — Settings → General → Repository name, например в `yawachat`.
   Адрес станет `https://yawaside.github.io/yawachat/`, старые ссылки GitHub будет
   перенаправлять. Сайт после этого продолжит работать без правок кода.
3. **Репозиторий-«корень»** — если назвать репозиторий `yawaside.github.io`,
   сайт откроется по короткому адресу `https://yawaside.github.io/`.
4. **Другой хостинг** — Cloudflare Pages, Netlify или Vercel дают бесплатный адрес вида
   `yawachat.pages.dev` / `yawachat.netlify.app` и поддержку своего домена.
   Для них достаточно публиковать содержимое папки `web/dist/` (команда сборки
   `npm run build:only`, каталог публикации `web/dist`).

Пункты 1–4 (кроме 3) меняются в настройках GitHub / у регистратора — из кода это сделать
нельзя, но код к любому из вариантов уже готов.
